# Source Material

This shelf preserves rough plans, exploratory conversations, discarded routes,
and other searchable material from Dragonbound's development.

## Status

**Nothing in this folder is canon merely because it appears here.** These files
record possibilities and authorial history. They may contain contradictions,
obsolete chapter numbering, superseded character ideas, continuity errors,
tool chatter, or plans that stopped being enjoyable in play.

When sources disagree, use this order of authority:

1. the written RP;
2. current canon, character, lore, location, and handoff files outside this
   folder;
3. the creators' latest explicit decisions;
4. this source-material shelf as evidence of earlier intent, not a command.

The story wins over the plan.
